# NoorAI Backend - Project Configuration

## Project Metadata

- **Name**: NoorAI Backend
- **Description**: NoorAI Backend API built with NestJS, TypeORM, and PostgreSQL
- **Version**: 0.0.1
- **License**: ISC
- **Repository**: git@github.com:hngprojects/noorAI-BE.git

## Technology Stack

- **Backend Framework**: NestJS
- **ORM**: TypeORM
- **Database**: PostgreSQL
- **Language**: TypeScript
- **Authentication**: JWT
- **API Documentation**: Swagger
- **Testing**: Jest

## Development Environment Setup

### Prerequisites

- Node.js (v18 or higher)
- PostgreSQL (v12 or higher)
- npm or yarn

### Installation Steps

1. Clone the repository

   ```bash
   git clone git@github.com:hngprojects/noorAI-BE.git
   cd noorAI-BE
   ```

2. Install dependencies

   ```bash
   npm install
   ```

3. Setup environment variables

   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

4. Build the application

   ```bash
   npm run build
   ```

5. Run database migrations

   ```bash
   npm run migration:run
   ```

6. Start development server

   ```bash
   npm run start:dev
   ```

7. Access API documentation at: `http://localhost:PORT/api/docs`

## Key Scripts and Commands

- `npm run build` - Build the application

- `npm run test:cov` - Run unit tests with coverage
- `npm run test:e2e` - Run end-to-end tests
- `npm run migration:create` - Create a new migration
- `npm run migration:run` - Run pending migrations

## Configuration Details

### Environment Variables

Required environment variables:

```bash
# Application
PORT=6001
NODE_ENV=development

# Database
DB_TYPE=postgres
DB_USERNAME=your_username
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
DB_NAME=your_database
DB_ENTITIES=dist/modules/**/*.model{.ts,.js}
DB_MIGRATIONS=dist/database/migrations/*{.ts,.js}
DB_SSL=false

# JWT
JWT_SECRET=your_secret_key
JWT_TIMEFRAME=3d
```

### Database Configuration

- Uses PostgreSQL as the primary database
- TypeORM for ORM with SnakeNamingStrategy to convert camelCase to snake_case
- Database synchronization is disabled (uses migrations instead)
- Automatic migration running on application startup

### API Configuration

- Global prefix: `/api/v1`
- Swagger documentation available at `/api/docs`
- CORS enabled
- Trust proxy enabled
- JWT authentication with Bearer token

### Testing

- Unit tests using Jest
- E2E tests configuration available
- Test coverage reporting supported
- Separate test environment configuration

## About NoorAI

NoorAI is a warm, intelligent, and faith-centered digital companion designed to help Muslims build a peaceful, consistent, and emotionally supportive relationship with the Qur'an. It brings together AI-guided reflections, a clean Qur'an reading experience, and essential daily worship tools—all in one calming, distraction-free space.

### Key Features

1. AI-Powered Qur'an Chat with Qur'anic references and explanations
2. Immersive Qur'an Reader with Uthmani script and translations
3. My Reflections - Private encrypted journaling with linked ayahs
4. Prayer Times & Reminders with accurate timings
5. Tasbih - Simple counter with persistent state
